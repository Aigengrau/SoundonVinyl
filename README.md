# ЗВУК НА ВИНИЛЕ с Павлом Катковым

Сайт авторского винилового шоу. Перебран в фирменном стиле экосистемы
**ФУНДАМЕНТ**: белый лист, линия, четыре цвета. Ведущий цвет направления
«Винил» — древесный `#7A4A21`.

**Открыть:** дважды кликните `index.html`. Сборка не нужна — ни Node, ни npm,
ни бэкенда. Всё работает из файлов.

## Дизайн-система

Полное описание стиля — в [`BRAND.md` сайта ФУНДАМЕНТ](https://github.com/Aigengrau/Fundament).
Здесь — то, что важно для этого сайта.

| Роль | Значение |
|---|---|
| Акцент направления | древесный `#7A4A21` (`--wood`, он же `--accent`) |
| Тушь · бумага | `#0B0B0B` · `#FFFFFF` |
| Остальные цвета экосистемы | `#FF9800`, `#1F5BFF`, `#12B5A5` — только узлами и линиями |
| Заголовки | Unbounded 500/600 |
| Текст | Golos Text 400/500/600 |
| Шкала кегля | отношение 1.25, `--step--1 … --step-5` через `clamp()` |
| Движение | 200–300 мс, ease-out, только проявление ≤ 14 px, лесенка 60 мс |

**Запретный список, которому следует вёрстка:** никакого Inter и system-ui
в заголовках; ни одного фиолетового пикселя; никаких градиентов; никаких трёх
карточек с эмодзи; не более четырёх цветов плюс чёрный и белый; ни теней,
ни скруглений, ни объёма.

Знак сайта — родственник знака ФУНДАМЕНТ: тот же белый квадрат в цветной рамке,
но все четыре стороны древесные, а вместо буквы **Ф** — пластинка из двух
окружностей и шпинделя.

## Что изменилось при перестройке

**Было:** Bootstrap 3 + jQuery 1.11 + slick + fancybox + Font Awesome + четыре
таблицы стилей, шрифт Source Sans Pro, тёмный фон, карусели, всплывающие модалки.

**Стало:** обычный HTML + CSS + 134 строки JavaScript, ноль зависимостей.

- **Снесены** `bootstrap`, `jquery`, `slick`, `fancybox`, `font-awesome`,
  `animate.css`, `styles__ltr.css`, `futurelegal-layout.css`, `script.js`.
- **Заголовок-плакат.** «ЗВУК НА ВИНИЛЕ» — это SVG-текст с `textLength`,
  поэтому строка всегда занимает ровно ширину контейнера и никогда не переносится.
- **Композиции Кандинского** — рукописный SVG: линии прорисовываются при загрузке
  через `stroke-dashoffset`, кольца пластинки медленно вращаются.
- **Фотографии** публикуются в чёрно-белом виде и раскрываются в цвет при наведении.
  Логотипы партнёров — так же.
- **Карусель из 56 фотографий** на главной заменена мозаикой из пяти кадров шоу:
  страница грузится в разы легче, а смотреть удобнее.
- **Формы** (заявка и подписка) больше не показывают модалку «Спасибо за подписку!»
  без отправки — они собирают письмо и открывают почтовую программу.
- **Тексты сохранены** — «О проекте», «Об авторе», все пять новостей, пять
  материалов «Рок & винил» и пять записей блога перенесены практически дословно.
  Правки: типографика (кавычки-ёлочки, тире, неразрывные пробелы), разбивка
  сплошных абзацев и одна замена по смыслу — в новости от 24 апреля 2020
  «на VK, Facebook и Instagram» заменено на «в социальных сетях» (см. пункт ниже).
- **Добавлено из презентации проекта** (то же, что на сайте ФУНДАМЕНТ): хроника
  2017–2025, Legal Vinyl Party, состав винилового тракта, список площадок,
  блок «Как устроено шоу» из шести номеров.
- **Ссылки на Facebook, Instagram и Twitter убраны** из подвала и контактов;
  оставлены ВКонтакте и Telegram — как на головном сайте экосистемы.
  Если ссылки нужны, верните их в подвал `index.html` и в блок «Быстрые контакты».

## Как всё устроено технически

- **Ноль зависимостей.** Шрифты подключены с Google Fonts. Для полностью
  автономного размещения скачайте Unbounded и Golos Text, положите
  в `assets/fonts/` и замените `<link>` на `@font-face`.
- **Формы без бэкенда.** `assets/js/main.js` собирает письмо и открывает почтовую
  программу на `katkov@rockonvinyl.ru`. Чтобы подключить настоящий приём заявок,
  замените тело функции `mail()` на `fetch()` к вашему эндпоинту (Formspree,
  Getform, собственный обработчик) — разметку менять не нужно.
- **Доступность:** семантические теги, `aria`-атрибуты у меню и знаков, видимый
  фокус, `aria-current` на активном пункте меню, поддержка `prefers-reduced-motion`,
  версия для печати.
- **Фотографии** в `assets/img/photo/` — веб-версии (до 1600 px, ~200 КБ).
  Исходники остались в `vinyl/` и `rock/`; имена файлов не менялись.

## Публикация

Сайт статический, подходит любой хостинг.

1. Залейте содержимое папки в репозиторий.
2. Cloudflare Pages → Create a project → Connect to Git → выберите репозиторий.
3. Build command — оставить пустым, Build output directory — `/` (корень).
4. Deploy. Дальше каждый `git push` обновляет сайт автоматически.

Так же просто разворачивается на GitHub Pages, Netlify, Vercel или обычном
хостинге по FTP.

## Что стоит дополнить

1. **Свежие новости.** Последняя запись — апрель 2020, а хроника проекта доходит
   до 2025 года. Материалы 2024–2025 (Legal Vinyl Party, «Советская коллекция
   винила», Legal Vinyl Talks) есть только строчкой в хронике — пришлите тексты
   и даты, вёрстка `newsproject.html` уже готова их принять.
2. **Фотографии в высоком качестве.** Кадры шоу взяты из презентации проекта.
   Если есть исходники — замените файлы в `assets/img/show/`, имена сохранены.
3. **Портрет автора** для страницы «Об авторе» — сейчас там знак, а не фотография.
4. **Юридические страницы:** политика конфиденциальности и оферта — нужны тексты.
   Сейчас чекбоксы согласия ссылок не имеют.
5. **Приём заявок** — см. выше про формы.
